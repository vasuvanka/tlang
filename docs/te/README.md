# Tlang డాక్యుమెంటేషన్ (తెలుగు)

![Tlang logo (అ / Aa)](https://vasuvanka.github.io/tlang/tlang-logo.png)

Tlang — తెలుగు కీవర్డ్లతో కూడిన సరళమైన కంపైల్డ్ ప్రోగ్రామింగ్ భాష. Go భాష నుండి ప్రేరణ పొందింది.

## Tlang అంటే ఏమిటి?

Tlang ఒక కంపైల్డ్ భాష. ఇది C కోడ్‌గా కంపైల్ అవుతుంది, తద్వారా మీరు ఏ ప్లాట్‌ఫార్మ్‌లోనైనా ఎగ్జిక్యూటబుల్‌ను నిర్మించవచ్చు. సింటాక్స్ తెలుగు కీవర్డ్లను ఉపయోగిస్తుంది — ఉదాహరణకు `okavela` (if), `lekapothe` (else), `malli` (for), `mallinchu` (return).

## ఇంగ్లీష్ డాక్యుమెంటేషన్

పూర్తి గైడ్లు మరియు రిఫరెన్స్ కోసం టూల్‌బార్‌లో **EN** సెలెక్ట్ చేసి ఇంగ్లీష్ డాక్యుమెంటేషన్ చూడండి.
