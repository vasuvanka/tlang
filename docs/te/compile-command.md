# Tlang కంపైల్ కమాండ్ (తెలుగు)

కంపైల్ కమాండ్ Tlang సోర్స్‌ను ఒక స్టెప్‌లో ఎగ్జిక్యూటబుల్ బైనరీగా కంపైల్ చేస్తుంది.

## ఉపయోగం

```bash
tlang compile మీఫైల్.tl అవుట్‌పుట్
# లేదా
tlangc compile మీఫైల్.tl అవుట్‌పుట్
```

1. **Tlang → C:** మీ `.tl` ఫైల్ C కోడ్‌గా కంపైల్ అవుతుంది  
2. **C → బైనరీ:** C కంపైలర్ (gcc/clang) ఎగ్జిక్యూటబుల్‌ను నిర్మిస్తుంది

వివరణాత్మక మార్గదర్శి కోసం టూల్‌బార్‌లో **EN** సెలెక్ట్ చేయండి.
