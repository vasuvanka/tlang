# Tlang కీవర్డ్లు మరియు ఆపరేటర్లు (తెలుగు)

## ప్రధాన కీవర్డ్లు

| తెలుగు | English | ఉపయోగం |
|--------|---------|--------|
| `okavela` | if | షరతు |
| `lekapothe` | else | else |
| `malli` | for | లూప్ |
| `mallinchu` | return | రిటర్న్ |
| `agu` | break | బ్రేక్ |
| `konasagu` | continue | కంటిన్యూ |
| `nirmanam` | struct | స్ట్రక్చర్ |
| `jatha` | map | మ్యాప్ టైప్ |
| `varasa` | range | మ్యాప్ ఇటరేషన్ |
| `sunyam` | nil | నిల్ విలువ |

## ఆపరేటర్లు

- అసైన్మెంట్: `<-`, బోర్రో
- అరిథ్మెటిక్: `+`, `-`, `*`, `/`, `%`
- తులనా: `==`, `!=`, `<`, `>`, `<=`, `>=`

వివరణాత్మక మార్గదర్శి కోసం టూల్‌బార్‌లో **EN** సెలెక్ట్ చేయండి.
