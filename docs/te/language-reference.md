# Tlang భాషా సూచన (తెలుగు)

Tlang సింటాక్స్, కీవర్డ్లు మరియు భాషా ఫీచర్ల పూర్తి సూచన.

## సోర్స్ ఫైల్స్

Tlang సోర్స్ ఫైల్స్ `.tl` ఎక్స్‌టెన్షన్ ఉపయోగిస్తాయి.

## ప్రవేశ బిందువు

ప్రతి Tlang ప్రోగ్రామ్‌కు `#prarambham()` ఫంక్షన్ అవసరం:

```tl
#prarambham() {
    // మీ కోడ్
}
```

## వేరియబుల్స్

- **ఇమ్యూటబుల్:** `@name = విలువ;`
- **మ్యూటబుల్:** `@!name = విలువ;`

## ఇంపోర్ట్

`#dhimpu("path")` లేదా `@alias = #dhimpu("path");`

## కన్‌కరెన్సీ

ఛానల్స్: `@ch channel[int];` `ch <- value;` `@x = <- ch;` స్పాన్: `tlang #fn(args);` — [Concurrency Architecture](../concurrency-architecture-suggestions.md) చూడండి.

వివరణాత్మక మార్గదర్శి కోసం టూల్‌బార్‌లో **EN** సెలెక్ట్ చేయండి.
