# Tlang ప్యాకేజీలు మరియు మాడ్యూల్స్ (తెలుగు)

ప్యాకేజీ సిస్టమ్ కోడ్‌ను పునర్వినియోగ మాడ్యూల్స్‌గా ఏర్పాటు చేయడానికి అనుమతిస్తుంది.

## ఇంపోర్ట్

ఫైల్ ఎగువ డిక్లేరేషన్ లేదు; ఇంపోర్ట్ చేయడానికి `#dhimpu` ఉపయోగించండి:

```tl
@fmt = #dhimpu("std/fmt");
#dhimpu("std/strings");
```

## విదిలిటీ నియమాలు

Go-శైలి: పెద్ద అక్షరంతో ప్రారంభమయ్యే ఐడెంటిఫైయర్స్ ఎక్స్‌పోర్ట్ చేయబడతాయి.

వివరణాత్మక మార్గదర్శి కోసం టూల్‌బార్‌లో **EN** సెలెక్ట్ చేయండి.
