# Tlang స్టాండర్డ్ లైబ్రరీ అవలోకనం (తెలుగు)

Tlang పూర్తి స్టాండర్డ్ లైబ్రరీని అందిస్తుంది — fmt, strings, json, http, crypto, testing మరియు 30+ మాడ్యూల్స్.

## కోర్ మాడ్యూల్స్

- **fmt** — ఫార్మాట్ చేసిన I/O
- **strings** — స్ట్రింగ్ ఆపరేషన్స్
- **math** — గణిత ఫంక్షన్లు
- **strconv** — స్ట్రింగ్ మార్పిడి

## సిస్టమ్

- **os**, **io**, **filepath**, **time**

## డేటా & ఎన్కోడింగ్

- **json**, **bytes**, **sort**, **hex**, **base64**, **csv**, **xml**, **protobuf**

## నెట్‌వర్కింగ్

- **http** — HTTP క్లయింట్ మరియు సర్వర్

వివరణాత్మక మార్గదర్శి కోసం టూల్‌బార్‌లో **EN** సెలెక్ట్ చేయండి.
