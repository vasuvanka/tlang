# Tlang ట్యుటోరియల్ (తెలుగు)

ఈ ట్యుటోరియల్ ప్రారంభం నుండి అడ్వాన్స్డ్ వరకు Tlang నేర్చుకోవడంలో సహాయపడుతుంది.

## విషయాలు

1. ప్రాథమిక సింటాక్స్ — వేరియబుల్స్, ఫంక్షన్లు
2. నియంత్రణ ప్రవాహం — `okavela`, `lekapothe`, `malli`
3. డేటా రకాలు — structs, slices, maps
4. ప్యాకేజీలు మరియు ఇంపోర్ట్స్ — `#dhimpu`

వివరణాత్మక మార్గదర్శి కోసం టూల్‌బార్‌లో **EN** సెలెక్ట్ చేసి ఇంగ్లీష్ ట్యుటోరియల్ చూడండి.
