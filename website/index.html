Install

One command per platform. Requires Rust, a C compiler (or bundled GCC on Windows), and OpenSSL. Full guide

curl -fsSL https://raw.githubusercontent.com/vasuvanka/tlang/main/install.sh | bash
iwr -useb https://raw.githubusercontent.com/vasuvanka/tlang/main/install.ps1 | iex
curl -fsSL https://raw.githubusercontent.com/vasuvanka/tlang/main/install.cmd -o install.cmd && install.cmd && del install.cmd

Quick Start

Your first program: #dhimpu imports a package, #prarambham is the entry point (like main).

@fmt = #dhimpu("std/fmt");

#prarambham() {
    fmt.Printf("Hello, Tlang!\n");
}

Save as hello.tl, then:

tlang run hello.tl
# or compile to executable
tlang compile hello.tl hello && ./hello

Why Tlang

  • Telugu keywords Readable syntax: okavela, lekapothe, malli, mallinchu
  • Compiles to C Portable binaries, no runtime. Use any C compiler and platform.
  • Standard library fmt, strings, json, http, crypto, testing, and 30+ modules.
  • Go-like design Immutability by default, explicit imports, clear error handling.

Philosophy

Tlang follows Go’s principles: simplicity (one clear way), explicitness (readable code), compile-time safety, and fast compilation.
